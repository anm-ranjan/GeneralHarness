Setup

    Settings are written to backend/agent/agent_config.yaml in the install folder. Reopen this any time from File → Setup….

    Install location

    The backend, its Python environment, your configuration and your data live in a folder you choose. The suggested folder is this app's per-user data folder. An existing install is reused: its configuration, data, environment and your own agents are kept.

      Fleet (optional)
      
      
      Run the app on more than one machine and switch between them in the UI. Each machine keeps its own projects and threads. Every machine needs the same host list, changing only which one is "this machine".
      
      
      
      
        
      
          
          
          
          
        
      
        
      Other machines. A loopback URL (127.0.0.1) is reached through an SSH tunnel, so give its SSH host and backend port; setup writes a tunnel script.
